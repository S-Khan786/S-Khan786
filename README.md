### 🤖 PR Sentinel — Autonomous AI Code Review Agent
> **Event-driven AI Agent executing automated, line-by-line security & code quality audits on GitHub PRs.**

`FastAPI` • `LangChain LCEL` • `ChromaDB` • `RAG` • `Next.js` • `PostgreSQL` • `Pytest`

- 🛡️ **HMAC-SHA256 Webhook Pipeline:** Ingests GitHub pull request webhooks and launches background asynchronous analysis pipelines.
- 🔍 **RAG-Powered Security Auditing:** Semantically retrieves internal security policies (OWASP/CWE) using ChromaDB and vector embeddings.
- 🎯 **Hallucination-Free Line Mapping:** Custom diff-parser algorithm eliminating AI line-number hallucinations before publishing inline comments.
- 🧪 **Enterprise Reliability:** 80+ Pytest suite validating retrieval accuracy, diff parsing, and connection-pooled SQLAlchemy queries.

### ⚡ CaseFlow — Multi-Role Workflow Management Platform
> **Full-stack state-machine platform handling case lifecycles with real-time sync, RBAC, and analytics.**

`Next.js` • `TypeScript` • `FastAPI` • `PostgreSQL` • `Redis` • `Docker` • `Nginx`

- 🔄 **Real-Time Event Delivery:** Integrated WebSockets with Redis Pub/Sub for per-case channel subscriptions and auto-reconnection.
- 🔐 **State Machine & RBAC:** Enforces strict role-based transitions, preventing unauthorized status shifts across multi-tier teams.
- 📁 **Pluggable Storage Engine:** Abstracted storage layer dynamically toggles between AWS S3, Cloudinary, and local storage via environment configurations.
- ⏱️ **Distributed Job Scheduling:** Celery Beat background cron jobs with exponential backoff retries for automated reminders.
